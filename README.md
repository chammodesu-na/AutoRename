# AutoRename

Windows 다운로드 폴더 감시 → **AI가 파일 내용을 읽고 이름을 자동으로 정리**하는 트레이 상주 프로그램.

`report.xls`, `print.png`, `undefined.json` 처럼 내용을 전혀 알 수 없는 파일명을
`20260908_카드사용내역_KB국민은행.xls` 같은 형태로 바꿔준다.

> 파일명만 봐도 뭔지 알 수 있으면 그대로 두고, 애매하면 3초 카운트다운 팝업으로 물어본다.

## 주요 기능

- **내용 기반 리네이밍** — 엑셀·워드·PDF·이미지·텍스트를 실제로 열어보고 이름을 짓는다.
  텍스트가 안 뽑히는 PDF는 첫 페이지를 이미지로 렌더해서 넘긴다.
- **다중 AI 공급자** — Gemini / OpenAI / Claude 중 선택. 설정 GUI에서 공급자와 API 키만 바꾸면 된다.
- **무료 → 유료 키 자동 전환** — 무료 키가 한도(429)에 걸리면 유료 키로 자동으로 넘어간다.
  분당 한도와 일일 한도를 구분해서, 일일 소진이면 그날은 무료 키를 건너뛴다.
- **사용자 정의 지침** — "카드 사용내역이면 카드 끝번호 4자리를 제목에 넣어줘" 같은 규칙을
  한글로 자유롭게 적으면 그게 최우선 적용된다.
- **자동 이동 규칙** — "조건 설명 + 목적지 폴더"를 등록해두면 AI가 조건에 맞다고 판단한 파일을 그리로 옮긴다.
- **수정 내용 학습** — 사용자가 AI 추천을 고치면 기록해뒀다가, 10건마다 패턴을 요약해 이후 프롬프트에 반영한다.
- **실행 취소**, **에러 파일 재시도**, **오래된 파일 확장자별 정리**.

## 설치

[Releases](../../releases)에서 `AutoRenameSetup.exe`를 받아 실행한다. 관리자 권한이 필요 없다.

설치 후 트레이 아이콘 → **환경 설정**에서 API 키를 넣어야 동작한다.

### "일반적으로 다운로드되지 않습니다" 경고

유료 코드 서명 인증서를 붙이지 않아서 나오는 SmartScreen 평판 경고다. 두 단계에서 나온다.

- **다운로드할 때** — Chrome: 다운로드 항목의 `⋮` → 계속(보관) / Edge: `⋯` → 유지 → 자세히 보기 → 무시하고 계속
- **실행할 때** — "Windows의 PC 보호" 파란 화면 → 추가 정보 → 실행

받은 파일이 맞는지는 릴리스 페이지에 적힌 SHA256 과 대조하면 된다.

```powershell
Get-FileHash .\AutoRenameSetup.exe -Algorithm SHA256
```

### 업그레이드

같은 설치 파일을 그대로 실행하면 된다. **설정·학습 기록은 홈 디렉터리에 있어서 그대로 유지된다.**
실행 중이면 설치 프로그램이 알아서 닫고 진행한다.

## API 키 발급

기본 공급자는 [Google AI Studio](https://aistudio.google.com/apikey)의 Gemini다. 무료 티어가 있다.

무료 한도는 **프로젝트 단위**로 걸린다. "무료 소진 시 유료로 자동 전환"을 쓰려면
유료 키는 **결제가 연결된 다른 프로젝트**의 키여야 한다. 같은 프로젝트에서 키를 하나 더 발급받으면
한도를 공유하므로 같이 막힌다.

## 소스로 실행

```bash
pip install -r requirements.txt
pythonw.exe tray_app.py
```

## 직접 빌드

```bash
build_exe.bat
```

그다음 [Inno Setup](https://jrsoftware.org/isinfo.php)으로 `installer.iss`를 컴파일하면
`Output\AutoRenameSetup.exe`가 나온다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `tray_app.py` | 진입점. 트레이 아이콘 + 환경설정 GUI |
| `rename_watcher.py` | 폴더 감시, 파일 안정화 대기, rename 실행, 토스트/팝업 |
| `file_namer.py` | AI 공급자 호출, 파일 내용 추출, 프롬프트 구성, 설정 로드 |

## 설정 파일

전부 사용자 홈 디렉터리(`~`)에 저장된다. **저장소나 설치 폴더에는 키가 들어가지 않는다.**

| 파일 | 내용 |
|---|---|
| `rename_watcher_config.json` | API 키, 감시 폴더, 사용자 지침, 이동 규칙 |
| `rename_watcher_learning_log.json` | 사용자가 직접 고친 이름 기록 |
| `rename_watcher_pattern_summary.json` | 위 기록에서 뽑은 패턴 요약 |
| `rename_watcher_failed_files.json` | 분석 실패 파일 (당일분만 유지) |
| `rename_watcher_quota_state.json` | 무료/유료 키 전환 상태, 유료 호출 건수 |
| `rename_watcher.log` | 동작 로그 (1MB 넘으면 최근 500줄만 유지) |

## 주의

이 프로그램은 **파일 내용을 AI 공급자의 API로 전송한다.** 무료 티어는 대개 입력 데이터를
학습·로깅에 활용하는 것이 이용 조건이다. 민감한 문서를 다루는 폴더를 감시 대상으로 지정할 때는
공급자의 데이터 처리 정책을 확인하고, 필요하면 학습 미사용이 보장되는 유료 API를 쓸 것.
